# Frontend - Hệ Thống Quản Lý Nhà Hàng

Đây là ứng dụng Frontend xây dựng bằng **Next.js** dành cho dự án Quản lý Nhà hàng Đa điểm.

## Công nghệ sử dụng
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Data Fetching:** React Query (TanStack Query)
- **Forms & Validation:** React Hook Form + Zod
- **Icons:** React Icons

## Cách chạy dự án

1. Cài đặt thư viện:
```bash
npm install
```

2. Khởi chạy môi trường Dev:
```bash
npm run dev
```

Mở trình duyệt tại [http://localhost:3000](http://localhost:3000).

> Xem kiến trúc và bản đồ Database chi tiết ở file README tại thư mục gốc của dự án.
